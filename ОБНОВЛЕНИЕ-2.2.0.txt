TELEGRAM ↔ MAX BRIDGE 2.2.0 — ОБНОВЛЕНИЕ

ЧТО ИЗМЕНИЛОСЬ

1. Видео из MAX больше 20 МБ больше не перекодируется.
   Оно отправляется в Telegram как исходный файл (документ): без обрезки,
   поворота, квадратного кадра и изменения качества.

2. Добавлено простое подключение нескольких публичных Telegram-каналов.
   В личном чате с основным Telegram-ботом повторяй команду:

   /tgk add https://t.me/channel_one
   /tgk add https://t.me/channel_two

   Каждый вызов занимает следующий свободный слот. Доступно три слота.
   Проверить их можно командой:

   /tgk

   Старые команды /tgk 1, /tgk 2 и /tgk 3 сохранены.

КАК ОБНОВИТЬ WINDOWS-СЕРВЕР

1. Останови Bridge в PowerShell из его папки:

   docker compose -f .\compose.yaml -f .\compose.large-files.yaml down

2. Сохрани резервную копию файла .env и папки data.
3. Распакуй этот архив поверх установленной папки с заменой файлов.
4. Не удаляй и не заменяй свой .env и папку data.
5. Запусти:

   .\large-files-start.cmd

6. В журнале должна появиться строка Bridge 2.2.0 запущен.

ВАЖНО ПРО ВИДЕО

Видео больше 20 МБ будет показано в Telegram как файл. Это сделано специально:
только так Telegram получает точную исходную копию без перекодирования.
