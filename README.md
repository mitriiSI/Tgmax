# Telegram ↔ MAX Bridge 2.2.0

## Что исправлено в 2.2.0

- Видео из MAX размером больше 20 МБ отправляется в Telegram исходным файлом без перекодирования, обрезки, поворота и изменения соотношения сторон.
- Добавлена простая регистрация следующего канала: команда `/tgk add ССЫЛКА` сама выбирает первый свободный слот.
- Старые команды с номерами `/tgk 1`, `/tgk 2`, `/tgk 3` полностью сохранены.

## Публичные каналы

Вернулась простая схема публичных каналов, которая не требует доступа к чужому каналу:

```text
чужой публичный канал t.me
        ↓ сервер читает публичную страницу
Telegram ↔ MAX Bridge
        ↓
личный MAX / MAX-группа / MAX-канал
```

Используются три независимых слота:

```text
/tgk 1 https://t.me/channel_one
/tgk 2 https://t.me/channel_two
/tgk 3 https://t.me/channel_three
```

Отдельный Telegram-бот, обычный Telegram-аккаунт на сервере и права администратора исходного канала **не нужны**.

## Обновление установленного сервера

1. В PowerShell в папке Bridge останови контейнеры:

```powershell
docker compose -f .\compose.yaml -f .\compose.large-files.yaml down
```

2. Сохрани копию `.env` и папки `data`.
3. Распакуй архив 2.2.0 поверх `C:\Bridge\telegram-max-bridge`.
4. Не удаляй `.env` и `data`.
5. Запусти:

```powershell
.\large-files-start.cmd
```

6. Обнови Console сочетанием `Ctrl + F5`.

## Настройка TGK

Все ссылки задаются **в личном чате с основным Telegram-ботом**, который уже используется мостом:

Самый простой способ — повторять команду `add`; второй вызов автоматически займёт TGK 2:

```text
/tgk add https://t.me/channel_one
/tgk add https://t.me/channel_two
```

Либо можно по-прежнему указывать слот вручную:

```text
/tgk 1 https://t.me/channel_one
/tgk 2 https://t.me/channel_two
/tgk 3 https://t.me/channel_three
```

Посмотреть состояние:

```text
/tgk
```

Проверить конкретную ссылку:

```text
/tgk 1 test
```

Сразу переслать последний пост для проверки:

```text
/tgk 1 load 1
```

Удалить слот:

```text
/tgk 1 off
```

Отключить или включить все три слота:

```text
/tgk off
/tgk on
```

При добавлении ссылки текущий последний пост отмечается как уже просмотренный, чтобы сервер не прислал старую ленту. Новые публикации после этого идут автоматически. Для мгновенной проверки используется `/tgk 1 load 1`.

## Куда приходит TGK в MAX

По умолчанию каждый слот приходит в личный чат с основным MAX-ботом.

Чтобы TGK 1 приходил в отдельную MAX-группу или MAX-канал:

1. Добавь основного MAX-бота в нужный чат.
2. Внутри этого чата напиши:

```text
/tgk 1 here
```

Для второго и третьего слота:

```text
/tgk 2 here
/tgk 3 here
```

Вернуть слот в личный чат:

```text
/tgk 1 dm
```

Также в личном чате MAX-бота можно прислать ссылку на MAX-группу или канал:

```text
/tgk 1 https://max.ru/...
```

## Bridge Console

Открой:

```text
http://127.0.0.1:8080/console
```

Справа находится блок **TGK 1–3**. Для каждого слота можно:

- вставить публичную ссылку;
- сохранить;
- проверить доступность;
- переслать последний пост;
- очистить слот;
- увидеть точную ошибку.

## Важное ограничение

TGK читает публичную веб-страницу `t.me/s/username`. Поэтому исходный канал должен иметь публичный username. Приватные ссылки `t.me/+...` не поддерживаются. Если интернет-провайдер сервера полностью блокирует веб-домен Telegram, в `/tgk 1 test` и Console будет показана конкретная сетевая ошибка. Начиная с 2.1.2 используются повторные попытки через `t.me`, `telegram.me` и `www.t.me`.

## Остальные функции

Сохраняются все функции предыдущей сборки: многопользовательские профили, Telegram Business ↔ MAX, MAX-группы контактов, файлы до 2 ГБ через локальный Telegram Bot API, живой прогресс, Web/Desktop Console, голосовые, история и резервная копия базы.
